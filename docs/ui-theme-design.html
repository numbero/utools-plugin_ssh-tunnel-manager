切换能力：工具栏三态控件（跟随系统 / 浅 / 深），选择持久化于 dbStorage，每次进入插件校准；「跟随」时实时响应系统外观变化。
状态色条：卡片左侧 3px 色条 + 状态芯片在亮色下同样以语义色扫读，不依赖强调蓝。
日志恒定深色：不随主题切换，终端质感与对比度保持稳定。
图标随主题：默认（含宿主 logo、静态指令、主题）使用深色；动态指令图标按解析主题注册深/浅版；应用内品牌标识以 CSS 变量着色，任何切换实时跟随。
