## 1. 产品概述

### 1.1 定位
运行在 uTools 插件平台上的 SSH 隧道管理器：以可视化方式创建、管理本机 SSH 端口转发隧道，支持**本地转发（-L）、反向转发（-R）、动态 SOCKS 代理（-D）**，隧道进程后台常驻、独立于 uTools 生命周期。

### 1.2 解决的问题
开发者访问内网服务、远程调试、反向暴露本地服务时依赖 SSH 隧道，但命令行方式存在痛点：
- 命令长、参数难记（`-L 127.0.0.1:3306:db.internal:3306 …`）
- 进程难管理：终端关了隧道就断，断了也不知道
- 无状态可视：是否存活、运行多久、为何失败全靠猜
- 多条隧道时来回切换终端窗口

### 1.3 目标用户与发布范围
- 作者本人，macOS 上的日常开发者；**本地自用**，不上架 uTools 应用市场
- 平台以 macOS 为主，代码预留跨平台兼容

### 1.4 为什么选择 uTools
- 启动器式快捷调用：主搜索框输入隧道名即可启停，比独立 App 更快
- 免安装独立应用，配置托管在 uTools 本地数据库（含加密存储能力）
- 界面技术栈自由（Chromium + Node.js），可完整调用系统 `ssh` 命令

## 2. 核心概念

| 概念 | 定义 |
|---|---|
| **隧道（连接配置）** | 一个 SSH 连接目标：主机、端口、用户、认证方式、高级选项。**一个隧道 = 一个 ssh 进程**，是启停与状态的基本单位 |
| **转发规则** | 挂在隧道下的端口映射，三种类型：**本地**（本机端口 → 远端可达的服务）、**反向**（服务器端口 → 目标服务）、**动态 SOCKS**（本机 SOCKS5 代理）。每条规则可独立启用/停用 |
| **状态** | `已停止` / `连接中` / `运行中` / `错误`（附失败原因分类） |

## 3. 典型用户场景

| # | 场景 | 用法 |
|---|---|---|
| S1 | 访问内网数据库 | 经跳板机把远端 MySQL 3306 转发到本机 13306，数据库客户端直连 13306 |
| S2 | 一条连接转发多个服务 | 同一跳板机连接挂 DB / Redis / 管理页多条本地转发，一次启动全部就绪 |
| S3 | 临时反向暴露 | 把本机开发站点用 `-R` 暴露到公网服务器端口，发给别人预览 |
| S4 | SOCKS 全局代理 | `-D 1080` 动态转发，浏览器/工具走 SOCKS5 |
| S5 | 后台常驻 | 启动隧道后关闭 uTools 去开会，回来重开插件仍能看到并管理隧道 |
| S6 | 快捷调用 | uTools 搜索框输入隧道名 → 直接「启动/停止」，不打开界面 |

## 4. 功能需求（v1）

### 4.1 隧道管理
- **FR-1** 新建 / 编辑 / 删除 / 复制隧道；删除需确认
- **FR-2** 连接字段：名称、主机地址、端口（默认 22）、用户名、备注
- **FR-3** 卡片式列表：状态色点、名称、`user@host:port`、规则数摘要、运行时长；点击展开规则明细
- **FR-4** 列表顶部搜索过滤（按名称/主机）

### 4.2 转发规则
- **FR-5** 每隧道多条规则，类型：本地 / 反向 / 动态
- **FR-6** 本地规则：本地绑定地址:端口 → 远程主机:端口（远程主机从服务器视角解析，如 `127.0.0.1`、`db.internal`）
- **FR-7** 反向规则：远程绑定端口 → 目标主机:端口（从服务器视角）
- **FR-8** 动态规则：本地绑定地址:端口（SOCKS5）
- **FR-9** 每条规则独立启用开关；停用规则不参与连接
- **FR-10** 端口合法性校验（1–65535）；同隧道内端口重复拦截，跨隧道重复给出提示

### 4.3 连接控制
- **FR-11** 一键连接/断开：一次性按全部启用规则建立（单个 ssh 进程携带多个 `-L/-R/-D`）
- **FR-12** 工具栏「全部启动 / 全部停止」
- **FR-13** 无启用规则时禁止启动并提示
- **FR-14** 编辑运行中隧道：保存后提示「重新启动后生效」

### 4.4 状态与监控
- **FR-15** 四态显示 + 颜色语义（灰=停止 / 琥珀脉冲=连接中 / 绿=运行中 / 红=错误）+ 运行时长
- **FR-16** 错误原因分类（中文可读）：认证失败、主机不可达/连接超时、DNS 解析失败、本地端口被占用、远端端口被占用（反向）、主机密钥异常、密钥文件缺失或权限问题、其他
- **FR-17** 日志：每隧道独立日志文件持久化（uTools 退出期间也保留启动段日志），界面查看尾部、支持刷新/清空
- **FR-18** 自动重连：仅网络类失败触发，退避重试（2/4/8 秒，最多 3 次）；认证失败永不自动重试

### 4.5 后台常驻与状态恢复（核心差异化能力）
- **FR-19** ssh 进程以脱离方式（detached）启动，**退出 uTools 隧道不断**
- **FR-20** 重新打开插件时自动接管：按已存 PID + 进程身份校验 + 端口探活确认存活，恢复「运行中」状态且运行时长连续
- **FR-21** 仅隐藏 uTools 窗口时：监控与日志记录不受影响

### 4.6 认证与安全
- **FR-22** 认证三选一：密钥文件（可附 passphrase）、密码、ssh-agent
- **FR-23** 密码与 passphrase 使用 uTools 加密存储（`dbCryptoStorage`），与隧道配置文档物理隔离；导入导出均不含秘密
- **FR-24** 密钥按文件路径引用（文件选择器选取），不读取内容入库
- **FR-25** 秘密仅通过内存传入子进程 stdin，不进入命令行参数、环境变量或日志；日志中密码提示行不落敏感内容
- **FR-26** ssh-agent 环境变量解析链（macOS GUI 应用拿不到 shell 环境是已知问题）：进程环境 → `launchctl getenv` → 用户 shell → 设置中手工指定

### 4.7 uTools 平台集成
- **FR-27** 动态指令：每隧道注册「启动 xx」「停止 xx」，主搜索框命中后**静默执行 + 系统通知反馈**，不弹插件窗口
- **FR-28** 静态指令：「SSH 隧道」打开主面板、「新建 SSH 隧道」直达新建表单
- **FR-29** 深浅色主题自动跟随 uTools/系统
- **FR-30** 窗口高度随视图（列表/表单/日志）自适应调整

### 4.8 数据管理
- **FR-31** 隧道配置存 `utools.db`（本地持久化）；秘密字段绝不入库文档
- **FR-32** 配置导入/导出为 JSON 文件（不含密码），覆盖导入前确认

### 4.9 健壮性
- **FR-33** 启动前预检本地端口占用：报错并给出占用进程线索（`lsof` 提示）
- **FR-34** 系统无 `ssh` 可执行文件时顶部红色横幅警示
- **FR-35** 防 PID 复用：接管/停止前校验进程命令行含本插件身份标记

## 5. 非目标（v1 明确不做）
流量统计、连接历史记录、定时任务、隧道分组、隧道外全局快捷键、Windows/Linux 专门验证、SSH 终端会话（仅隧道）、多设备同步冲突处理。

## 6. 非功能需求
| 类别 | 要求 |
|---|---|
| 兼容性 | macOS 为主（本机 OpenSSH 9.x 已验证）；运行环境受限 Node 14+ / Chromium 91 |
| 性能 | 100 条隧道内列表即时渲染；启停操作响应 < 200ms；状态变更推送延迟 < 1s |
| 可靠性 | 进程崩溃/被杀 10 秒内反映到界面；状态恢复接管成功率 > 99%（本机场景） |
| 安全 | 见 4.6；日志文件权限 600、目录 700 |
| 约束 | 插件不请求外部网络资源、不动态加载外部 JS（uTools 平台规则） |

## 7. 数据模型（摘要）
- **隧道文档**（`utools.db`，`_id: tunnel_*`）：连接信息 + 认证元数据（仅布尔标记 `hasPassword/hasPassphrase`）+ 高级选项 + 规则数组 + 运行时状态 `{pid, startedAt}`
- **秘密**（`dbCryptoStorage`，`stm_secret_<tunnelId>`）：`{password?, passphrase?}`
- **动态指令**：每隧道 `start_<id>` / `stop_<id>` 两个 feature

完整字段定义见架构详设存档（本地计划文件，未随仓库发布）；要点已汇总于本文 §7 与代码注释。

## 8. 验收标准（端到端，macOS 本机 sshd）
| 用例 | 通过标准 |
|---|---|
| 本地转发 | `curl 127.0.0.1:<本地口>` 命中远端服务 |
| SOCKS | `curl -x socks5h://…` 成功访问外网 |
| 反向转发 | 服务器侧端口可达目标服务 |
| 密码/密钥/agent 认证 | 各自连接成功；错误密码明确报「认证失败」且不循环重试 |
| **常驻接管** | 退出 uTools 后隧道不断，重开插件状态/时长恢复 |
| 端口冲突 | 本地口被占时启动前拦截；远端口被占时报错分类正确 |
| 动态指令 | 搜索框启停不弹窗 + 收到通知 |
| 主题 | 系统明暗切换后界面跟随 |
